# Install Veilix

## Requirements

| Item | Requirement |
| --- | --- |
| Windows | Windows 10 version 2004 (build 19041) or later, or Windows 11 |
| Architecture | x64 |
| Runtime | [.NET 10 Desktop Runtime for Windows x64](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) |
| Storage | A writable folder for the extracted app and its local settings |

## Download and run

1. Open [Veilix Releases](../../releases) and expand **Assets**.
2. Download the **Veilix-Windows-x64** ZIP.
3. If needed, install **.NET Desktop Runtime 10** using the Windows **x64** installer on Microsoft's download page.
4. Right-click the Veilix ZIP and choose **Extract All**. Keep the files together in a writable folder such as `Documents\Veilix`.
5. Open the extracted folder and double-click **Veilix.exe**. Look for the island at the top of the selected display or for the Veilix icon in the Windows notification area.

## Choose English and your display

1. Click the island to open the panel, then click the gear icon.
2. Select **English** under **Dil**. The settings page switches to English immediately.
3. In **Settings → Category → Display**, choose the display and panel size.
4. Click the section name to jump to a feature. Click outside the panel or press **Esc** to close the expanded view.

## Optional device setup

- Start playback in Spotify to use the default media integration. To show other compatible players, turn on **Show media from other apps** under the Media settings category.
- Pair Bluetooth devices in Windows first. Connection controls and battery display depend on the device and driver.
- For an external display, brightness control requires a monitor and connection that support it. You may need to enable DDC/CI in the monitor's own settings.
- To enable weather, use the Weather settings category to search for a city and select a match.

## Update or remove

Quit Veilix from its notification-area icon before replacing the extracted app files. To keep your preferences and history, back up its local **data** folder. If **Start with Windows** is enabled, turn it off in the System settings category before removing the app folder. File-shelf copies are stored separately under **Documents → Veilix → Raf**.
